# Retrolarium Kit documentation

How the kit builds projects and what each game's editable resources look like.

- [toolchains.md](toolchains.md): the assemblers the kit ships and how they are
  pinned, cached and licensed.
- [nes_resources.md](nes_resources.md): the NES resource bundle (CHR, palettes,
  nametables) and its transactional build.
- [nes_text.md](nes_text.md): fixed-width NES text fields and screen text.
- [fds_synthesis.md](fds_synthesis.md): FDS wave RAM and volume programs of the
  Disk System games.
- [smb_world.md](smb_world.md), [smb_levels.md](smb_levels.md),
  [smb_music.md](smb_music.md): Super Mario Bros. courses, level areas and
  music.
- [pacman_maze.md](pacman_maze.md), [pacman_screens.md](pacman_screens.md),
  [pacman_sound.md](pacman_sound.md): Pac-Man maze, screens and sound.
